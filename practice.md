# Javascript Practice

I learned in Lecture 1 that JavaScript has several built-in data types such as `number`, `string`, `boolean`, `object`, `array`, and `function`. I also learned that JavaScript has both `null` and `undefined`, where `null` means an intentional empty value and `undefined` means a value has not been assigned yet.

```javascript
typeof null
```

```javascript
object
```

- JavaScript has different built-in data types
- `null` represents an intentional empty value
- `undefined` means a value has not been assigned yet
